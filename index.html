How to use University Timetable

Import your timetable once, then see it week by week. Click a session to edit it or add a note.

  1. Sign in to Orari, UniMi's timetable website.
  2. Choose the timetable of your course of study (and year).
  3. Switch to the Events List view.
  4. Click Export Excel — you get an .xls file.
  5. Here, click Import Excel and choose that file.
  1. Download the template:
  2. Fill in one row per session (lesson or exam) under the header row: Day as dd-mm-yyyy, Hour as HH:MM - HH:MM (24-hour), Course. Lecturer, Room and Notes are optional. Don't rename the header.
  3. Save the file (.xlsx, .xls or .csv).
  4. Here, click Import Excel and choose that file.
Good to know
  • 4-hour (or 6-hour) blocks are split into 2-hour slots.
  • Importing a newer file again keeps your notes and edits.
  • Exams or extra courses (e.g. a language class)? + Add session; for a weekly class tick Repeat weekly.
  • Open this guide again any time with ? Help.
